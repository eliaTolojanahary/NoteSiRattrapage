========================================================
  REGLES DE GESTION (RAPPEL)
========================================================

1. Note maximale
   Si une note est saisie plusieurs fois pour la même matière,
   on conserve uniquement la note la plus élevée.

2. Matières optionnelles (S4 uniquement)
   Options disponibles : dev / bddres / web
   -> On retient l'option ayant la meilleure note.
   -> Les deux autres options sont ignorées dans le calcul.

3. Moyenne L2
   Moyenne L2 = (moyenne_S3 + moyenne_S4) / 2
   Chaque moyenne semestrielle est calculée APRES application
   des règles 1 et 2 ci-dessus.
